# 补充 1：KL 散度作为损失函数

[← 返回框架](../../README.md)

## 一、定义与几个关键性质

对两个**离散概率分布** $p, q$ 在同一支撑集上：

$$D_{KL}(p \,\|\, q) = \sum_i p_i \log \frac{p_i}{q_i} = \mathbb{E}_{i \sim p}\!\left[\log \frac{p_i}{q_i}\right]$$

连续分布把求和换成积分即可。

**它能做 loss 的三个性质**：

| 性质 | 数学 | 实际意义 |
|------|------|---------|
| 非负 | $D_{KL}(p \,\|\, q) \geq 0$ | loss 有下界 0 |
| 极小点唯一对应分布相等 | $D_{KL}(p \,\|\, q) = 0 \iff p = q$ | 最优解 = 完美对齐 |
| 处处可微（在 q > 0 处） | 梯度存在 | 能反传 |

**但它不是距离**：

- 不对称：$D_{KL}(p \,\|\, q) \neq D_{KL}(q \,\|\, p)$
- 不满足三角不等式
- 上界无穷（当 $q_i \to 0$ 而 $p_i > 0$ 时 → $\infty$）

→ 严格说叫"散度"（divergence），不叫"度量"（metric）。

---

## 二、它就是你早就用过的交叉熵（CE）

把 KL 展开：

$$
D_{KL}(p \,\|\, q) = \sum_i p_i \log p_i - \sum_i p_i \log q_i = -H(p) + H(p, q)
$$

- $H(p) = -\sum p_i \log p_i$：$p$ 的熵
- $H(p, q) = -\sum p_i \log q_i$：交叉熵

→ 当 $p$ **固定**（如 one-hot 标签、teacher 输出）时，$H(p)$ 是常数：

$$\min_\theta D_{KL}(p \,\|\, q_\theta) \quad \Longleftrightarrow \quad \min_\theta H(p, q_\theta)$$

**分类任务用的 cross-entropy loss 本质上就是 KL**，只是把 $-H(p)$ 这个常数项丢了（梯度上等价）。

更具体的对应：

| 你以为在用的 | 实际上等价于 |
|------------|------------|
| 监督分类的 CE loss | $D_{KL}(\text{one-hot label} \,\|\, p_{\theta})$ |
| Label smoothing | $D_{KL}(\text{smoothed label} \,\|\, p_{\theta})$ |
| 知识蒸馏（Hinton）| $D_{KL}(p_{teacher} \,\|\, p_{student})$ |
| Language modeling 的 next-token loss | $D_{KL}(\delta_{w_t} \,\|\, p_\theta(\cdot \mid w_{<t}))$ |

## 三、不对称的方向问题 ⭐ 选错方向 = 训出不同模型

这是用 KL 时**最容易踩的坑**。

### 3.1 Forward KL：$D_{KL}(p \,\|\, q)$ —— mode-covering

写开就是 $\sum_i p_i \log(p_i / q_i)$，**期望沿着 $p$ 取**。

直观：哪里 $p_i > 0$，就**强迫** $q_i$ 也得 > 0（否则 $\log(p_i / 0) = \infty$ → loss 爆）。所以 $q$ 必须**覆盖 $p$ 的所有 mode**，画图是"摊开来包住 $p$"。

```
         p (双峰)              q 学到的形状
        ▲    ▲                ▄▆█▆▄▄▆█▆▄
        █    █       →        ↑ q 把两个峰都覆盖
        █    █                  （宁可多覆盖，不能漏）
```

适用场景：
- 监督学习 / 标准蒸馏
- target $p$ 是真实分布、不能漏掉任何 mode 的场景
- **DSA indexer**（不能漏主 attention 关注的位置）

### 3.2 Reverse KL：$D_{KL}(q \,\|\, p)$ —— mode-seeking

期望沿着 $q$ 取。哪里 $q_i = 0$，那一项就 = 0，不惩罚。所以 $q$ 可以**集中到 $p$ 的一个 mode** 上，对其他 mode 完全不管。

```
         p (双峰)              q 学到的形状
        ▲    ▲                  ▆█▆
        █    █       →          ↑ q 只挑一个峰，忽略另一个
        █    █                
```

适用场景：
- VAE encoder ($D_{KL}(q_\phi(z|x) \,\|\, p(z))$)
- **RLHF / PPO / DPO** 中的 KL 约束项 ($\beta \cdot D_{KL}(\pi_\theta \,\|\, \pi_{ref})$) —— 防止 policy 漂移
- Variational inference
- 想让模型"自信、专注于单一答案"的场景

### 3.3 一张总结表

| 方向 | 写法 | 期望沿 | 行为 | 典型用法 |
|------|------|--------|------|---------|
| Forward | $D_{KL}(p \,\|\, q)$ | $p$ | mode-covering（摊开） | 蒸馏、监督学习、DSA indexer |
| Reverse | $D_{KL}(q \,\|\, p)$ | $q$ | mode-seeking（聚焦） | VAE、RLHF、DPO |

→ **选哪个方向不是细节，是建模决策**。问一句"我希望 q 漏 mode 还是覆盖所有 mode"就能定下来。

### 3.4 对称化变体

如果两个方向都想要 / 不确定该选哪个：

- **JSD**（Jensen-Shannon Divergence）：
  $$\text{JSD}(p, q) = \tfrac{1}{2} D_{KL}(p \,\|\, m) + \tfrac{1}{2} D_{KL}(q \,\|\, m), \quad m = \tfrac{p+q}{2}$$
  对称、有界（$\leq \log 2$）、是 metric 的平方
- **总变差距离** (TV)：$\tfrac{1}{2} \sum |p_i - q_i|$，对称、有界、是 metric
- **Wasserstein**：考虑分布几何结构，WGAN 用的就是这个

但深度学习里 **forward / reverse KL 仍是绝对主流**，因为它跟交叉熵亲缘最近，工程上最熟。

## 四、工程实现的几个坑

### 4.1 $\log 0$ 数值问题

如果 $q_i = 0$ 而 $p_i > 0$，forward KL → $\infty$，梯度爆。

实操对策：
- **永远从 logits 出发**，配 `log_softmax` 直接拿到稳定的 $\log q_i$
- 不要"先 softmax 再 log" → 会丢精度
- PyTorch `F.kl_div(input, target)` **故意要求** `input` 是 log-prob，`target` 是 prob：

```python
import torch.nn.functional as F

# student_logits, teacher_logits: shape [B, ..., C]
loss = F.kl_div(
    F.log_softmax(student_logits, dim=-1),   # 注意是 log_softmax
    F.softmax(teacher_logits, dim=-1),       # target 是 prob
    reduction='batchmean',                    # 对 batch 取均值（数学上正确的 reduction）
)
```

⚠️ `reduction='mean'` 会**除以元素总数**（含 class 维），数学上不对；用 `'batchmean'` 才是真 KL。

### 4.2 蒸馏时的 temperature

知识蒸馏（KD）的标准 trick：

$$p^{(T)} = \text{softmax}(z / T)$$

$T > 1$ → 分布变软（"dark knowledge" 浮现，非 top-1 类别也有信号）。

蒸馏 loss 通常是：

$$\mathcal{L} = T^2 \cdot D_{KL}(p_{teacher}^{(T)} \,\|\, p_{student}^{(T)})$$

$T^2$ 是为了补偿梯度被 softmax 缩放的因子（Hinton 2015 原文）。常见 $T \in [2, 10]$。

### 4.3 Forward KL 的稀疏 target 优化

如果 $p$ 是 one-hot（监督分类），forward KL = CE，直接用 CE 即可（更稳）。

如果 $p$ 比较稀疏但不是 one-hot（如 label smoothing 后），KL 等价于 CE + 一个常数。

### 4.4 Reverse KL 的不可导问题

Reverse KL $D_{KL}(q_\theta \,\|\, p)$ 里的期望是沿 $q_\theta$ 取，但 $q_\theta$ 参数本身就在变 → 直接采样不可导，得用：
- **Reparameterization trick**（VAE 标准做法：$z = \mu + \sigma \cdot \epsilon$）
- **REINFORCE / Policy gradient**（RLHF 走这条）

这就是为什么 RLHF 是个"RL 问题"而不是"监督学习问题"——reverse KL 的梯度估计天然带方差。

## 五、在 LLM 各章节里的具体出场

| 章节 | 场景 | 形式 | 方向 | 备注 |
|------|------|------|------|------|
| §6.2 | DSA lightning indexer 蒸馏 | $D_{KL}(p_{attn} \,\|\, p_{indexer})$ | forward | 不能漏主 attention 高分位置 |
| §9.2 | MoE 负载均衡 aux loss | KL 到 uniform | 双向都用过 | 让 expert 利用率均衡 |
| §10.5 | 知识蒸馏（teacher → student）| $D_{KL}(p_T^{(T)} \,\|\, p_S^{(T)})$ | forward | 配 temperature |
| §11.3 | RLHF / PPO | $\beta \cdot D_{KL}(\pi_\theta \,\|\, \pi_{ref})$ | reverse | 防 policy 飘走 |
| §11.4 | DPO | 隐式包含 KL 约束（推导出 closed-form loss） | reverse | DPO 本质就是 RLHF 的 reverse-KL 解析解 |
| §11.5 | GRPO / RLVR | 同 PPO，KL 项不可少 | reverse | 否则训崩 |
| - | VAE | $D_{KL}(q_\phi(z|x) \,\|\, p(z))$ | reverse | ELBO 的正则项 |

→ **KL 不仅能当 loss，它是深度学习里最普遍的 loss 家族之一**。

---

## 六、一句话总结

- KL 当 loss 完全合法，**它就是交叉熵的"完整形式"**
- 选 forward 还是 reverse 取决于"你希望模型漏 mode 还是覆盖 mode"
- 工程上永远从 logits + log_softmax 出发，避免 log(0)
- 蒸馏配 temperature；RL 场景配 reparameterization 或 REINFORCE
