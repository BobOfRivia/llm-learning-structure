# 补充 5：熵与交叉熵（从"信息量"讲起）

[← 返回框架](../../README.md)

> 这是一篇**打地基**的工具笔记，是 [KL 散度作为损失函数](01-kl散度作为损失函数.md) 的前置。
> 几乎所有分类 / 语言模型的 loss（cross-entropy loss）、蒸馏、RLHF 的 KL 项，底层都是熵和交叉熵。
> 很多人直接背下 $H(p)=-\sum p\log p$ 这个公式，却不知道它**为什么**长这样。这篇就从零把这个"为什么"讲透。

---

## 零、一句话预告

| 概念 | 一句话 | 公式 |
|------|--------|------|
| 信息量 | 一件事发生，带来多少"惊讶" | $-\log p_i$ |
| **熵** $H(p)$ | 一个分布**平均有多不确定** | $-\sum_i p_i \log p_i$ |
| **交叉熵** $H(p,q)$ | 真实是 $p$，却拿 $q$ 去编码，**平均要多花多少** | $-\sum_i p_i \log q_i$ |
| KL 散度 | 用错 $q$ 比最优**多浪费**多少 | $H(p,q) - H(p)$ |

读完全篇你会发现：**这四个东西是一条链，环环相扣，一点都不玄。**

---

## 一、先问：怎么衡量"一件事发生带来多少信息"？

信息论的出发点不是熵，而是一个更小的问题：

> 一个概率为 $p_i$ 的事件**真的发生了**，它带给你多少"信息"？

我们想找一个函数 $I(p)$，把"概率"映射成"信息量"。它得满足几条符合直觉的要求：

### 要求 1：越不可能的事，信息量越大

- "太阳明天升起"（$p \approx 1$）：你早知道了，**信息量 ≈ 0**。
- "明天你家门口掉陨石"（$p$ 极小）：**信息量爆炸**，你会到处跟人说。

→ 所以 $I(p)$ 必须是**递减**的：$p$ 越大，$I$ 越小。

### 要求 2：确定的事，信息量为 0

- $p = 1$ 的事（必然发生），信息量应该正好是 $0$。

### 要求 3：两件独立的事一起发生，信息量应该**相加**

- 你今天"中了彩票"($p_1$) 而且"被雷劈了"($p_2$)，这两件独立的事。
- 直觉上，总的"惊讶程度"应该是两份惊讶**加起来**。
- 但两件独立事件同时发生的**概率是相乘**的：$p_1 \cdot p_2$。

→ 于是我们需要一个函数，能把"输入相乘"变成"输出相加"：
$$I(p_1 \cdot p_2) = I(p_1) + I(p_2)$$

**世界上把"乘法变加法"的函数，就是对数 $\log$。**

### 把三条要求拼起来 → 信息量的定义

同时满足"递减 + $p{=}1$ 时为 0 + 乘变加"的函数，只能是：

$$\boxed{I(p_i) = -\log p_i = \log \frac{1}{p_i}}$$

- 前面加负号（或写成 $\log \frac 1 p$），是因为 $p \in (0,1]$ 时 $\log p \le 0$，取负变正 → 信息量非负。✅ 递减
- $p = 1 \Rightarrow -\log 1 = 0$。✅ 确定的事信息量为 0
- $-\log(p_1 p_2) = -\log p_1 - \log p_2$。✅ 乘变加

> **log 的底数是多少？**
> - 底为 **2** → 单位是 **bit**（比特），最常用来讲直觉：信息量 = "要问几个是/否问题才能确定结果"。
> - 底为 **e** → 单位是 **nat**（奈特），深度学习框架默认（因为 `torch.log` 是自然对数）。
> - 换底只差一个常数倍，不影响任何结论。本篇讲直觉用 bit，写 loss 时是 nat。

## 二、熵 = 信息量的"平均"

上面 $I(p_i)$ 说的是**某一个**事件发生后的信息量。但一个随机变量有很多种可能结果，我们想知道：

> **平均**每抽一次样，会得到多少信息量？

"平均"在概率里就是**期望**——把每个结果的信息量，按它发生的概率加权求和：

$$\boxed{H(p) = \sum_i p_i \cdot \underbrace{(-\log p_i)}_{\text{该结果的信息量}} = -\sum_i p_i \log p_i}$$

这就是**熵**。注意它有两层身份，记住任意一个都行：

1. **不确定性的度量**：分布越"摊平"（各结果概率越接近），越难猜中下一次是什么，熵越大。
2. **最优编码的平均长度**：如果你要给每个结果设计一套二进制编码，最省的方案下，平均每个结果需要 $H(p)$ 个 bit（香农编码定理）。

### 用抛硬币把直觉钉死

用 $\log_2$（单位 bit）：

| 分布 | 计算 | 熵 | 直觉 |
|------|------|-----|------|
| 均匀硬币 $[0.5, 0.5]$ | $-0.5\log_2 0.5 \times 2$ | **1 bit** | 最不确定，恰好要 1 个"是/否"问题 |
| 灌铅硬币 $[0.9, 0.1]$ | $-0.9\log_2 0.9 - 0.1\log_2 0.1$ | **0.47 bit** | 大概率正面，没那么不确定 |
| 作弊硬币 $[1, 0]$ | $-1\log_2 1 - 0$ | **0 bit** | 结果已定，根本不用问 |
| 均匀骰子 $[\frac16]\times 6$ | $-\frac16\log_2\frac16 \times 6$ | **2.58 bit** | 6 种可能，比硬币更不确定 |

**规律一句话：越均匀（越乱）熵越大，越极端（越接近 one-hot）熵越小，确定的事熵为 0。**

```
熵 H(p)
 ▲
1├──────  ● 均匀 [0.5,0.5]  （最不确定）
 │      ╱   ╲
 │    ╱       ╲
 │  ╱           ╲
0└●───────────────●──►  p(正面)
 0     0.5        1
 全反面           全正面
 （都是确定的事，熵=0）
```

## 三、交叉熵 = 用"错的编码方案"要花多少

现在做一个关键的思想实验，交叉熵就是从这里冒出来的。

### 场景：真实分布是 $p$，但你手上只有一个错的 $q$

假设某个事件真实的分布是 $p$，但你**不知道 $p$**，你手里只有一个估计 $q$（比如模型的预测输出）。你只能**按 $q$ 去设计编码方案**：

- 你以为事件 $i$ 的概率是 $q_i$，所以给它分配的编码长度是 $-\log q_i$。
  （概率越大的东西给越短的编码，这是最省的策略——但你是按 $q$ 来判断"谁概率大"的。）
- 可是现实中，事件 $i$ **真正**出现的频率是 $p_i$，不是 $q_i$。

那么，**平均**每次实际要花的编码长度是多少？还是求期望，但要注意期望的两个角色分工不同：

$$\boxed{H(p, q) = \sum_i \underbrace{p_i}_{\text{真实频率：外面按 }p\text{ 加权}} \cdot \underbrace{(-\log q_i)}_{\text{编码长度：按 }q\text{ 设计}} = -\sum_i p_i \log q_i}$$

这就是**交叉熵**。"交叉"二字就体现在这里——**外面的权重用 $p$，log 里面用 $q$，两个分布交叉在一起。**

### 和熵并排一看，区别只有一个字母

$$
H(p) = -\sum_i p_i \log \boldsymbol{p_i}
\qquad\qquad
H(p, q) = -\sum_i p_i \log \boldsymbol{q_i}
$$

**唯一的差别：log 里面是"真实的 $p$"，还是"你猜的 $q$"。** 其他一模一样。

- 当你猜得完全对，$q = p$，交叉熵就退化回熵：$H(p,p) = H(p)$。
- 当你猜得越离谱，用错编码浪费越多，$H(p,q)$ 就比 $H(p)$ 越大。
- 可以证明**永远有 $H(p,q) \ge H(p)$**（最优就是最优，拿错分布只会更差或持平）。

## 四、把三者串成一条线：KL = 交叉熵 − 熵

既然 $H(p,q) \ge H(p)$，我们自然想问：**用错 $q$ 到底比理论最优多花了多少？** 一减就知道：

$$
\boxed{D_{KL}(p \,\|\, q) = \underbrace{H(p,q)}_{\text{用 }q\text{ 的实际开销}} - \underbrace{H(p)}_{\text{最优开销（下界）}}}
$$

- 猜对了（$q=p$）→ 一分不多花 → $D_{KL} = 0$。
- 猜错了 → 多花的部分就是 KL，且**永远 $\ge 0$**（这就是 KL 非负性的来源）。

> **这解释了训练里一个常见困惑：为什么分类明明在最小化 KL，代码里却只写 cross-entropy？**
> 因为标签 $p$ 是**固定**的（比如 one-hot），它的熵 $H(p)$ 是个**常数**（one-hot 时还正好 $=0$）。
> 优化模型参数 $\theta$ 时，减一个常数不改变最优解、不改变梯度：
> $$\min_\theta D_{KL}(p \,\|\, q_\theta) \iff \min_\theta H(p, q_\theta)$$
> 所以直接优化交叉熵就够了。**cross-entropy loss 本质就是 KL，只是省掉了没用的常数项。**
> 详细展开见 [KL 散度作为损失函数 §二](01-kl散度作为损失函数.md)。

## 五、落到深度学习：cross-entropy loss 到底在算什么

拿最常见的**单标签分类**（图像分「猫/狗/鸟」，或 LM 预测 next token）举例。

- 真实标签 $p$ 是 **one-hot**，例如真值是"狗" → $p = [0, 1, 0]$。
- 模型输出经过 softmax 得到预测概率 $q = [0.2, 0.7, 0.1]$。

代入交叉熵公式：

$$
H(p, q) = -\big(\,0\cdot\log 0.2 \;+\; 1\cdot\log 0.7 \;+\; 0\cdot\log 0.1\,\big) = -\log 0.7 \approx 0.357
$$

**看这个式子的三个洞察：**

1. **one-hot 让求和塌成一项**：$p$ 里只有真类是 1，其余是 0，所以整个求和只剩"真类"那一项。
   → 分类的 cross-entropy loss 就退化成一句话：**$-\log(\text{模型给正确答案的概率})$**。
2. **它在逼模型"把正确答案的概率往 1 顶"**：$q_{\text{真类}} \to 1$ 时 $-\log q \to 0$（loss 最小）；$q_{\text{真类}} \to 0$ 时 $-\log q \to +\infty$（狠狠惩罚）。
3. **它天然是个好的训练信号**：预测越接近真值，loss 越小且平滑可导，能反向传播。

```
loss = -log(q_真类)
 ▲
 │╲
 │ ╲          预测越接近真值(q→1)，loss 越小
 │  ╲
 │   ╲___
 │       ‾‾‾───____
0└──────────────────► q_真类
 0                  1
 (猜错，重罚)     (猜对，loss→0)
```

> **补一句实现细节**：真实代码里不会"先 softmax 再 log"，而是用 `log_softmax` 一步到位（数值更稳，避免 $\log 0$）。PyTorch 的 `F.cross_entropy(logits, target)` 直接吃 **logits**，内部合并了 `log_softmax + NLL`。归一化函数的坑见 [logits 与归一化函数](03-logits-与归一化函数.md)。

## 六、几个容易混的点（快问快答）

**Q1：熵和交叉熵的"方向"能反吗？$H(p,q)$ 和 $H(q,p)$ 一样吗？**
不一样。$H(p,q)=-\sum p_i\log q_i$，外面权重是 $p$；$H(q,p)=-\sum q_i\log p_i$，外面权重是 $q$。谁在外面当"真实频率"是有讲究的——这也是 KL 不对称的根源，见 [KL §三 forward/reverse](01-kl散度作为损失函数.md)。

**Q2：为什么 loss 会是"负 log"，负号哪来的？**
不是刻意加负号。信息量本身就是 $-\log p$（因为 $p\le 1$ 时 $\log p \le 0$，取负才是正的信息量）。loss 只是信息量的期望，负号是"与生俱来"的。

**Q3：熵一定 ≥ 0 吗？交叉熵呢？**
对离散分布，两者都 $\ge 0$（因为每个 $-\log p_i \ge 0$）。但**连续分布的"微分熵"可以为负**，那是另一个话题，分类/LM 用不到，先不管。

**Q4：为什么不用"预测错了几个"这种更简单的指标当 loss？**
"错了几个"（0-1 loss）不可导、梯度处处为 0，没法训练。交叉熵**平滑可导**、对"错得离谱"惩罚重（$-\log$ 在 0 附近趋于无穷），是天然适合梯度下降的 loss。

**Q5：label smoothing 在干嘛？**
把 one-hot 的 $p$（如 `[0,1,0]`）抹软成 `[0.05, 0.9, 0.05]`。此时 $p$ 不再是 one-hot，$H(p)$ 不为 0，但训练目标仍是最小化交叉熵。效果是让模型别对某一类"过度自信"。

## 七、一分钟总复习

1. **信息量** $-\log p$：一件事越不可能发生，它真发生时带来的信息越多。用 log 是为了让独立事件的信息量能相加。
2. **熵** $H(p)=-\sum p_i\log p_i$：信息量的**期望**，衡量一个分布**平均有多不确定**。越均匀熵越大，确定的事熵为 0。
3. **交叉熵** $H(p,q)=-\sum p_i\log q_i$：真实是 $p$，却拿 $q$ 编码的**实际平均开销**。和熵的唯一区别是 log 里面用 $q$ 而非 $p$。永远 $\ge H(p)$。
4. **KL** $=H(p,q)-H(p)$：用错 $q$ 比最优**多浪费**的开销，非负，$q=p$ 时为 0。
5. **分类 loss**：标签是 one-hot 时，cross-entropy loss $=-\log(\text{正确类的预测概率})$，也就是被简化过的 KL。
