## 〇、本节回答什么

> 大模型最早被广泛接受的"智商"代理：通用知识 + 多步推理。本节回答：
> - MMLU 为什么成为事实标准，又为什么 2024 年后被认为"饱和 + 污染"
> - MMLU-Pro / BBH / GPQA Diamond 的设计差异
> - **打分方式**（letter-logits vs generation vs CoT）会让同一模型同一 benchmark 差 5–15 个点
> - 2025 年面试如何报数才不被认为"刷榜"

---

## 一、MMLU（Hendrycks et al., 2020）

### 1.1 设计

- **57 个 subject**：STEM / 人文 / 社科 / 法律 / 医学 ...
- 共 **15908 道四选一**单选题（dev 5 / val 1.5K / test 14K）
- 测的是**知识 + 浅推理**（高中到专业资格证级别）
- 默认 **5-shot**（dev 集里抽 5 个 demo 同 subject）

### 1.2 评分方式（这是坑）

MMLU 有 **三种主流报数方式**，差别巨大：

| 方式 | 做法 | 典型差异 |
| --- | --- | --- |
| **letter logits / harness 默认** | 把 prompt + "Answer:" 给模型，比较 4 个 letter token 的 logit | 主流报数 |
| **option logits / cloze** | 比较 4 个 option full-text 的 logprob | 比 letter 高 1-3 点 |
| **generate-then-parse** | 生成自由文本再正则抽答案 | 比 letter 高 2-5 点（chat 模型尤甚） |
| **5-shot CoT** | 加 "think step by step" + 生成 | 比 0-shot 高 3-8 点（大模型） |

> 面试坑：Llama 报的 MMLU 是 letter logits，OpenAI/Anthropic 报的常是 CoT generation，两者**不可直接比较**。

### 1.3 饱和现象

```
2020 MMLU 发布时 SOTA 32%（GPT-3 175B）
2023        GPT-4 = 86%
2024        Claude 3.5 Sonnet ≈ 88%
2025        Top 模型集中在 88-91%，进入"刷不动"区
```

原因：
1. **天花板逼近**：题本身有 ~5% 标注噪声 + 歧义题
2. **训练数据污染**：很多 MMLU 题在 web 上有泄露（见 §13.7）
3. **多选题信号有限**：4 选 1 给 25% 随机基线

→ 业界开始转向 MMLU-Pro / GPQA。

## 二、MMLU-Pro（TIGER-Lab, NeurIPS 2024）

### 2.1 设计动机

MMLU 三大问题：
1. 选项太少（4 个）→ 蒙对率高
2. 推理深度浅
3. 大量题在预训练数据里出现过

### 2.2 改造方案

| 改造 | MMLU | MMLU-Pro |
| --- | --- | --- |
| 选项数 | 4 | **10** |
| 题量 | 14K | 12K |
| 学科聚类 | 57 → | 14 大类 |
| 推理深度 | 浅 | 加入 STEM / 数学多步 |
| 噪声题清理 | ❌ | ✅（人工核） |
| CoT 默认 | 否 | **是** |

### 2.3 报数变化

```
GPT-4o:          MMLU 88.7 → MMLU-Pro 72.6  (Δ ≈ 16)
Claude 3 Opus:   MMLU 86.8 → MMLU-Pro 68.5
Llama-3.1 405B:  MMLU 88.6 → MMLU-Pro 73.3
o1-preview:      → 78.0
o1:              → 82.0
```

→ MMLU-Pro 拉开了"快思考 vs 慢思考"模型的差距。

## 三、BIG-Bench Hard (BBH, Suzgun et al. 2022)

### 3.1 来源

BIG-Bench 是 Google 2022 年 200+ 任务的大杂烩 benchmark，BBH 是从中挑出**当时模型表现 <人类平均**的 **23 个 hard subset**。

### 3.2 任务类型（部分典型）

- **boolean_expressions**：逻辑求值
- **causal_judgement**：因果判断
- **date_understanding**：日期算术
- **disambiguation_qa**：代词指代
- **dyck_languages**：括号匹配
- **formal_fallacies**：形式谬误
- **geometric_shapes**：从 SVG 描述识图
- **multistep_arithmetic_two**：多步算术
- **navigate**：方位推理
- **object_counting** / **penguins_in_a_table**：结构化推理
- **tracking_shuffled_objects**：状态追踪

### 3.3 评测惯例

- 默认 **3-shot CoT**
- 报 **average accuracy**（23 个任务取均值）
- exact match（生成式打分）

### 3.4 现状

```
GPT-4:    86.7
Claude 3.5 Sonnet: 93.1
Llama-3.1 405B:    81.6
o1:       未公开（≈饱和）
```

BBH 已基本饱和，2024 之后业界更看 GPQA / MMLU-Pro。

## 四、GPQA Diamond（Rein et al., 2023） — MMLU 接班人之一

虽然 README 里 §13.1 只列了 MMLU/MMLU-Pro/BBH，但 2024-2025 年实际面试问到"知识 + 推理"基准，**GPQA Diamond 是不可不知**的对照项。

### 4.1 设计

- **Google-Proof Q&A**：物理 / 化学 / 生物 **PhD 级题**
- 设计目标：连 PhD 同领域专家也只能拿 81%，跨领域专家仅 34%（且允许 Google）
- **Diamond 子集**：198 道经过双盲一致性筛选的最难题

### 4.2 为什么"反污染"

- 题来自 PhD 出题人原创
- 题面有大量 unicode 符号 + 化学结构 → web 上几乎没有
- 选项 4 个但**没有"明显错"的干扰项**

### 4.3 报数

```
Claude 3.5 Sonnet:  59.4 (Diamond)
GPT-4o:             53.6
o1:                 78.0
o1-pro / R1:        ≈75–78
人类专家:           65（同领域）
```

→ GPQA 是 2024 测出 o1 提升最显著的 benchmark 之一。

## 五、几个易混的"通用"基准

| Benchmark | 题型 | 主要测什么 | 状态 |
| --- | --- | --- | --- |
| **MMLU** | 4-choice, 57 subj | 知识广度 | 饱和 + 污染 |
| **MMLU-Pro** | 10-choice, 14 cat | 知识 + 推理 | 主流 |
| **BBH** | 23 hard tasks | 多步推理 | 饱和 |
| **GPQA Diamond** | 4-choice, PhD | 深度推理 + 反污染 | 主流 |
| **AGIEval** | 高考 / SAT / LSAT 真题 | 标准化考试 | 中文圈用得多 |
| **C-Eval / CMMLU** | 中文 MMLU 风格 | 中文知识 | 中文模型必报 |
| **TriviaQA / NQ** | open-domain QA | 检索 + 知识 | 经典但少用 |
| **ARC-Challenge** | 小学科学题 | 推理 | 小模型还用 |
| **HellaSwag** | 句子续写 | 常识 | 饱和 |
| **WinoGrande** | 代词消解 | 常识 | 饱和 |

> 面试小坑：HellaSwag / ARC / WinoGrande 现在叫"**HuggingFace Open LLM Leaderboard 老六件套**"——2024 年初被 MMLU-Pro / GPQA / MUSR / MATH-L5 / IFEval / BBH 取代为 **OpenLLM v2**。

## 六、打分细节里的陷阱

### 6.1 chat template 影响

用 base model 评 MMLU 直接拼 prompt 即可；评 **chat / instruct 模型时必须套对应 chat template**（system+user）。

```python
# ❌ 错：直接 raw 拼接
prompt = f"Q: {q}\nA:"

# ✅ 对：用 chat template
prompt = tokenizer.apply_chat_template(
    [{"role": "user", "content": q}],
    add_generation_prompt=True,
)
```

不套 chat template，Llama-3 Instruct 的 MMLU 可能跌 5+ 点。

### 6.2 letter-bias

模型对 "A/B/C/D" 四个 letter 的 prior 不均：训练数据里 A 出现频率最高，模型有"**A-bias**"。修正方式：

- **Symmetric MMLU**：把同一道题换 4 种 option 排列再均值（贵但准）
- **Calibrate-then-decide**：用空 prompt 算 4 个 letter 的先验，做 softmax 减法

### 6.3 5-shot 还是 0-shot

- **base model**：5-shot
- **chat model**：0-shot CoT（5-shot 反而扰乱 chat 行为）
- **reasoning model (o1/R1)**：必须 0-shot；few-shot 会污染它的 reasoning trace

## 七、典型报告方式（Llama-3.1 / DeepSeek 风格）

```
| Benchmark           | Setting           | Score |
|---------------------|-------------------|-------|
| MMLU                | 5-shot, no CoT    | 88.6  |
| MMLU (CoT)          | 0-shot CoT        | 88.0  |
| MMLU-Pro            | 5-shot CoT        | 73.3  |
| BBH                 | 3-shot CoT        | 81.6  |
| GPQA (Diamond)      | 0-shot CoT        | 50.7  |
```

每行必须写清 **shots / CoT / harness** 三件套，否则不可信。

## 八、关键问答

**Q1：为什么 2024 年还有人盯着 MMLU 看？**
A：因为它是**历史可比性最好的 benchmark**，所有 base model 都报过。看趋势线、模型代际比较时还是首选。但绝对分数（>85）已无区分度，跨模型对比改看 MMLU-Pro / GPQA。

**Q2：base model 和 chat model 评 MMLU 的差距是哪来的？**
A：三个来源——(1) chat template 套不套 (2) letter logits vs generate 抽 (3) RLHF 让 chat 模型不愿做"machine-readable"的 A/B/C/D 输出，更愿生成解释，导致 letter logit 不准。许多 chat 模型 letter logit 报数低于自身真实水平。

**Q3：MMLU-Pro 改 10 选 1 之后噪声基线变了吗？**
A：随机基线从 25% → 10%，但模型水平也下降了 ≈15 点，**信噪比反而更高**。最大的好处是题更难、可拉开 reasoning 模型差距。

**Q4：BBH 是 few-shot CoT 还是 zero-shot CoT？**
A：原始论文是 **3-shot CoT**（每个任务 3 个范例），生成式 exact match。但 chat 模型现在普遍报 0-shot CoT。

**Q5：letter-bias 是什么？怎么消除？**
A：训练数据里 A 出现次数最多，模型 prior 偏 A → 真题里答案如果是 A，模型答对但**不是真的会**。消除：把每道题的 4 个 option 做 4 次 cyclic permutation，每次模型选完后映射回原 option，取多数。代价是 4× 算力。

**Q6：HellaSwag / ARC 还有用吗？**
A：基本没用了，小模型（< 3B）评 ablation 还看，旗舰模型已饱和。HuggingFace Open LLM v2 把它们换成 IFEval / MUSR / MATH Level-5 / BBH / GPQA / MMLU-Pro 六件套。

**Q7：怎么从这些 benchmark 看出"reasoning 模型 vs 非 reasoning 模型"差距？**
A：看 **MMLU-Pro / GPQA / AIME / MATH** 四个**推理深度高**的 benchmark：o1 比 GPT-4o 提升 15–30 点；但在 MMLU / HellaSwag / TriviaQA 这些**知识广度型**上几乎不涨。这是判断"长 CoT 是否真的带来推理增益"的核心证据。
