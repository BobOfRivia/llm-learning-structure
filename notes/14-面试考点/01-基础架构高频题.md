## 一、Tokenization 与数据（→ §1）

### Q1.1 BPE / BBPE / SentencePiece 三者区别？ ⭐

**【答 30s】**
- **BPE**：基于字符（character）做合并，OOV 情况下要 fallback；GPT-2 用过
- **BBPE**：基于 byte（utf-8 字节）做合并，**字节级永远无 OOV**；GPT-3/4、Llama、Qwen、DeepSeek 全用 BBPE
- **SentencePiece**：是工具/框架（而不是算法），内部可选 BPE 或 Unigram；它的关键是**把空格也当 token**（`▁`）、**不依赖 pre-tokenizer**、对中日韩友好；T5 / Llama 1/2 / Gemma 都用 SentencePiece

**【加分项】**
- BBPE 的优势：处理 emoji、繁体、阿语、代码 byte 串无 OOV，词表小（Llama-3 用 128K）
- Unigram (Kudo, 2018) 是从大词表往下裁剪，BPE 是从小词表往上合并
- tiktoken 是 OpenAI 自研的 BBPE 实现，速度远快于 HF tokenizers（用 Rust + 特殊 cache）

**【追问】**
1. 为什么 Llama-3 把词表从 32K → 128K？→ 非英语压缩比、tokens/word 降低 → 训推都省 token
2. 中文一个汉字一般几个 BBPE token？→ 1-3 个，常用字 1-2 个
3. Tokenizer 词表怎么影响 scaling law？→ 词表大 ⇒ 单 token 信息密度高 ⇒ 等 token 数下信息量更多

---

### Q1.2 为什么 LLM 普遍用 BBPE 而不是 word-level / char-level？ ⭐

**【答 30s】**
- **word-level**：词表爆炸（百万级），OOV 严重，无法处理新词/代码
- **char-level**：序列过长（一句话 100+ tokens），训推都贵
- **BBPE**：中间路线 + byte 兜底，词表 32K-256K，**对任意输入都能编码**

**【加分项】**
- 实测压缩比：英文 ~4 chars/token，中文 ~1.5 chars/token（DeepSeek）；代码 ~3 chars/token
- 数字 tokenization 是大坑：GPT-2 把 12345 拆成 4 个 token，导致算术差；Llama-3 / DeepSeek 单独训了 0-999 三位整数为一个 token，AIME 数学分大幅提升

**【追问】**
1. 字符级 vs byte 级有什么区别？→ byte 级永远 256 个基础单元、不依赖 unicode 表
2. 听说过 MegaByte / Byte-Latent Transformer？→ Meta 2024 提出端到端字节模型，去掉 tokenizer

---

### Q1.3 预训练数据怎么去重 / 过滤？ ⭐⭐

**【答 30s】**
- **去重**：URL 级 → 文档级（MinHash LSH）→ 段落/句子级（fuzzy）
- **质量过滤**：规则过滤（语言、长度、字符比例）→ 模型过滤（classifier 打分，如 FineWeb-Edu 用教育性分类器）→ perplexity 过滤
- **合成数据**：Phi 系列 textbook、Llama-3 合成代码、Nemotron-4 合成 SFT
- **配比**：domain 配比靠 DoReMi / RegMix 等算法学习权重

**【加分项】**
- FineWeb (HuggingFace, 2024) 提供 15T token、用 datatrove 做大规模去重
- Llama-3 报告用了 15T tokens（90% 英语 + 8% 多语 + 2% 代码）
- DSIR / RHO-Loss 是数据选择（subset selection）方向

**【追问】**
1. MinHash 怎么工作？→ shingle → minhash 签名 → LSH 桶找近邻
2. FineWeb-Edu 的 classifier 怎么训？→ Llama-3 评分高质量页 → 蒸馏出小 classifier
3. 合成数据的"模型崩塌"风险？→ Shumailov 2024 NeurIPS Best Paper，递归用合成数据会丢长尾

### Q1.4 Chinchilla scaling law 结论是什么？为什么 Llama-3 又"打破"了它？ ⭐⭐

**【答 30s】**
- **Chinchilla（2022）**：固定 compute 预算下，**模型大小 N 和训练 token 数 D 应当大致 1:20**（D ≈ 20N）
- 例：70B 模型最优 1.4T tokens
- **Llama-3 70B 训了 15T tokens** ≈ 200 tokens/param，远超 Chinchilla
- 原因：**Chinchilla 只优化训练成本**；**Llama-3 优化的是推理成本 + 部署性价比**，小一点的模型多训成本几乎不变但部署便宜

**【加分项】**
- Kaplan 2020 早期 scaling law 推荐 N 增长比 D 快，被 Chinchilla 推翻
- "Beyond Chinchilla"（Sardana et al., 2024）正式给出 inference-aware 公式
- DeepSeek-V3 671B（37B 激活）训了 14.8T，同样是"小激活 + 多数据"

**【追问】**
1. 训练 FLOPs 公式？→ `6ND`（forward + backward 共 6 倍）
2. 为什么 6 不是 2？→ 1 forward + 2 backward = 3，再乘 2 是因为每参数有 forward+gradient 两次访存（简化口径）
3. emergent ability 是不是 scaling law 的产物？→ 部分（Wei 2022）；但 Schaeffer 2023 NeurIPS Best Paper "Are Emergent Abilities a Mirage" 质疑评测离散化造成假象

## 二、经典 Transformer 与现代化改进（→ §2）

### Q2.1 Self-Attention 公式 + 为什么除以 √d？ ⭐

**【答 30s】**

$$
\mathrm{Attn}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V
$$

- Q/K/V 都是 `[seq_len, d_model]` × `[d_model, d_k]` 投影出来
- 除以 √d 是为了让 dot-product 方差稳定在 ~1，否则 d 大时 softmax 进入饱和、梯度消失

**【加分项】**
- 推导：假设 Q,K 元素 iid 标准正态（均值 0、方差 1），`QK^T` 元素方差为 d，所以除以 √d 让方差 = 1
  - 设 $q,k \in \mathbb{R}^d$，$q_l, k_l \overset{iid}{\sim} \mathcal{N}(0,1)$，且 $q$ 与 $k$ 独立
  - 单项 $q_l k_l$：$\mathbb{E}[q_l k_l] = \mathbb{E}[q_l]\mathbb{E}[k_l] = 0$（独立）
  - 单项方差：$\mathrm{Var}(q_l k_l) = \mathbb{E}[(q_l k_l)^2] - 0 = \mathbb{E}[q_l^2]\mathbb{E}[k_l^2] = 1\cdot 1 = 1$
  - 点积 $q\!\cdot\!k = \sum_{l=1}^{d} q_l k_l$ 是 d 个独立同分布零均值项之和
  - 由独立和方差可加：$\mathrm{Var}(q\!\cdot\!k) = \sum_{l=1}^{d} \mathrm{Var}(q_l k_l) = d$，标准差 $=\sqrt{d}$
  - 故 $\frac{q\cdot k}{\sqrt{d}}$ 方差 = 1，softmax 输入分布与 d 解耦，避免维度增大时进入饱和区
- causal mask：上三角填 `-inf`，softmax 后变 0
- multi-head：并行多个低维投影，每个 head 看不同语义子空间

**【追问】**
1. 不除 √d 会怎样？→ 大 d 下 softmax 极端，attention 退化成 one-hot，梯度几乎为 0
2. 多头注意力 head 数选多少？→ d_model / head_dim，head_dim 通常 64 或 128
3. 注意力复杂度？→ 时间 O(n²d)，空间 O(n²)

### Q2.2 位置编码：Sinusoidal → Learned → RoPE → ALiBi 演化为什么 RoPE 赢？ ⭐⭐

**【答 30s】**
- **Sinusoidal**（原版 Transformer 2017）：加性、不可学，外推有限
- **Learned**（BERT/GPT-2）：可学但**强绑定训练长度**，外推就崩
- **ALiBi**（Press 2021）：在 attention score 上加位置 bias `-m·|i-j|`，**天然外推**但表达力弱
- **RoPE**（Su 2021，Llama/Qwen/DeepSeek 都用）：在 Q,K 上做**复数旋转**，**相对位置自然涌现**，外推可通过插值（PI / NTK / YaRN）扩展

**【加分项】**
- RoPE 核心：每对 dim 用一个不同频率 `θ_i = 10000^(-2i/d)` 做旋转
- 数学性质：`<RoPE(q,m), RoPE(k,n)> = f(q,k, m-n)` —— 只依赖相对位置差
- ALiBi 的优势是零参数 + 外推自然；劣势是高频信息丢失，长上下文质量不如 RoPE+YaRN

**【追问】**
1. RoPE 怎么扩展到 128K？→ Position Interpolation / NTK-aware / YaRN / LongRoPE，详见 §8 §14.3
2. base θ=10000 为什么？→ 经验值，长上下文常调到 500K / 1M（Llama-3.1）
3. 为什么 MLA 还要单独搞 decoupled RoPE？→ MLA 压缩 KV 破坏了 RoPE 旋转结构，DeepSeek 给一部分维度单独走 RoPE

---

### Q2.3 LayerNorm vs RMSNorm 区别？为什么主流换 RMSNorm？ ⭐

**【答 30s】**
- **LayerNorm**：`(x - μ) / σ · γ + β` —— 减均值除标准差，有 γ/β 两个学习参数
- **RMSNorm**（Zhang 2019）：`x / RMS(x) · γ` —— **不减均值**，只用 RMS，去掉 β

```
RMS(x) = sqrt(mean(x²))
```

- 主流换 RMSNorm 原因：
  - **计算少**：不算 mean
  - **效果几乎一样**：Llama 实验显示训练稳定性和最终 loss 无显著差异
  - **省一组参数**：去掉 β

**【加分项】**
- Llama / Qwen / DeepSeek / Gemma 全用 RMSNorm
- 还有 DeepNorm（在 Post-Norm 上做缩放，扩到 1000 层）
- BatchNorm 在 LLM 几乎不用（依赖 batch 统计、不友好 autoregressive）

**【追问】**
1. Pre-Norm vs Post-Norm？→ Pre 训练稳定但表达力略弱；Post 表达力强但深层难收敛；现代 LLM 全部 Pre-Norm
2. RMSNorm 不减均值会出问题吗？→ 实测不会，输入分布自然居中
3. 为什么 GPT-2 是 Pre-LN？→ "On Layer Normalization in the Transformer" (Xiong 2020) 证明 Pre-LN 不需要 warm-up

### Q2.4 FFN 演化：ReLU → GeLU → SwiGLU？ ⭐

**【答 30s】**

| 形式 | 公式 | 用在哪 |
| --- | --- | --- |
| ReLU FFN | `W₂·ReLU(W₁x)` | 原版 Transformer |
| GeLU FFN | `W₂·GeLU(W₁x)` | BERT / GPT-2 / GPT-3 |
| **SwiGLU** | `W₂·(Swish(W₁x) ⊙ W₃x)` | **Llama / Qwen / DeepSeek 主流** |

- SwiGLU 来自 GLU 家族（Dauphin 2017），引入一个**门控**乘法
- 实证：同等参数下 PPL 更低、收敛更快
- 注意：SwiGLU 有 3 个矩阵（W₁,W₂,W₃），为了保持参数量持平，hidden_dim 一般取 `8/3 · d_model`

**【加分项】**
- GLU 家族还有 GeGLU、ReGLU；SwiGLU 是 Shazeer 2020 "GLU Variants Improve Transformer"
- Swish = SiLU = `x · sigmoid(x)`
- 为什么门控有用？→ 类似 LSTM 的门，让 FFN 学到稀疏激活 / 选择性传递

**【追问】**
1. Swish 和 GeLU 在数学上差多远？→ 形状几乎一样，Swish 计算更便宜
2. FFN 为什么是 4×d_model？→ Transformer 原文经验值，实际 SwiGLU 用 8/3×d 保持参数等价
3. 听说过 ReLU² 这种激活？→ Primer (So 2021) 用 ReLU²，但没流行

### Q2.5 残差连接为什么必要？ ⭐⭐

**【答 30s】**
- **梯度流**：`y = x + f(x)`，反向传播 `∂y/∂x = 1 + ∂f/∂x`，**梯度至少有 1 兜底**，可以堆深
- **信息保留**：低层 token embedding 一直传到顶层
- 没有残差，深层 Transformer 直接不收敛

**【加分项】**
- He 2015 ResNet 引入；Transformer 原文 (Vaswani 2017) 沿用
- DeepNet (Wang 2022) 给残差加 `α` 缩放系数，把 Post-LN 扩到 1000 层
- "Residual stream" 视角（Anthropic 力推）：把残差看作一条共享的读写总线，每个 attention/FFN block 读写它

**【追问】**
1. 残差里加不加 LayerNorm？→ Pre-Norm: `x + f(LN(x))`；Post-Norm: `LN(x + f(x))`
2. 听说过 "residual stream" 这个概念？→ Anthropic interpretability 用语，把残差看成一条读写带宽有限的总线，attention 在它上面"写"，下游 head 来"读"

### Q2.6 Encoder-Decoder 推理时怎么交互？ ⭐⭐

**【答 30s】**
- **训练**：encoder 一次 forward 所有 source；decoder teacher-forcing 一次 forward 所有 target
- **推理**：encoder 一次 forward（cache 出 K_enc, V_enc）→ decoder 逐 token autoregressive 生成，每步对 encoder 输出做 cross-attention（Q 来自 decoder，K/V 来自 encoder 缓存）
- decoder 自身的 self-attention 仍然有 KV-cache

**【加分项】**
- 注意 cross-attention 的 K_enc/V_enc 只算一次（encoder 输出固定）
- T5 / Whisper 是典型 enc-dec 架构
- decoder-only 没有 cross-attention，只有 self-attention

**【追问】**
1. T5 和 BART 区别？→ T5 是"text-to-text"统一 prefix；BART 是 BERT-like encoder + GPT-like decoder
2. Whisper 为什么是 enc-dec？→ speech token 序列做 cross-attention，target text 自回归

## 三、三大架构范式（→ §3）

### Q3.1 为什么 decoder-only 赢了？ ⭐⭐

**【答 30s】**
三个原因：
1. **scaling 更友好**：单一目标（next-token prediction），数据无需 align，所有原始文本都能用
2. **In-Context Learning 涌现**：decoder-only 在 few-shot ICL 上显著强于 encoder-decoder
3. **KV-cache 友好**：自回归解码自然分摊计算（prefill + decode 范式）

而 encoder-decoder 的优势（双向编码）在 seq2seq 任务被 in-context learning 取代后基本失效。

**【加分项】**
- "What Language Model Architecture and Pretraining Objective Work Best for Zero-Shot Generalization?" (Wang 2022) 系统对比，decoder-only + next-token 在 ICL 强
- T5 / BART 在专门 seq2seq fine-tuning 仍占优，但通用 chatbot 都是 decoder-only
- DeepSeek-OCR / Gemini 把 vision 也走 decoder-only patch token

**【追问】**
1. 为什么 BERT 这条路被冷落？→ 不能生成、ICL 弱、需要任务级 fine-tune
2. encoder-decoder 还有什么不可替代场景？→ ASR (Whisper)、翻译（NLLB）、强 conditional 生成
3. 听说过 PrefixLM 这种折中？→ 前缀双向后缀单向，UL2 / GLM 用过

---

### Q3.2 In-Context Learning 为什么会涌现？ ⭐⭐⭐

**【答 30s】**
- **现象**：足够大的 decoder-only LLM 能仅看几个例子就完成新任务（few-shot）
- 主流解释：
  1. **隐式梯度下降**（von Oswald 2022 ICML Outstanding）：transformer attention 等价于在 demonstration 上做 implicit 梯度下降
  2. **Bayesian inference / induction heads**（Olsson, Anthropic）：模型学到 pattern matching head（A→B, A→? 触发 B）
  3. **任务向量**（Hendel 2023）：demonstration 在中间层形成一个 task vector，可被剥离提取
- 涌现条件：模型规模 + 数据多样性 + decoder-only autoregressive 目标

**【加分项】**
- Schaeffer 2023 NeurIPS Best Paper：很多"emergence"是评测离散化产生的视觉假象，但 ICL 本身是真涌现
- "Many-shot ICL"（Anthropic 2024）：100+ examples 比 few-shot 强很多，对长上下文模型尤其有用

**【追问】**
1. ICL 和 fine-tune 区别？→ ICL 不改权重、单次 inference；fine-tune 改权重、需要 backward
2. ICL 例子顺序敏感吗？→ 非常敏感（Lu 2022），permutation 能差十几个点
3. 听说过 induction head？→ Anthropic 给 attention head 起的名字，看到 [A][B]...[A] 会预测 [B]

---

### Q3.3 涌现（emergence）是不是评测假象？ ⭐⭐⭐

**【答 30s】**
- **正方**：Wei 2022 "Emergent Abilities" 给出多个突变曲线（如 3-digit add 在某个规模突然能做）
- **反方**：Schaeffer 2023 NeurIPS Best Paper "Are Emergent Abilities a Mirage"，论点：用 exact match 度量天然离散，换 token-level edit distance 后变成平滑曲线
- **综合**：
  - 度量方式上的 emergence 确实部分是假象
  - 但**质变能力**（ICL、CoT、code completion）确实在某规模才出现
  - 2025 reasoning 模型在 AIME 上从 < 10% → > 80% 的跃迁是新一轮 emergence

**【追问】**
1. CoT 算 emergence 吗？→ Wei 2022 认为是（小模型加 CoT 反而更差）
2. 这对 scaling law 有什么启发？→ 不能只盯 loss/PPL，要盯下游能力，且要早期就准备好测能力的 benchmark

## 四、关键问答（综合）

### Q4.1 一行说清"现代 Llama 架构"和原版 Transformer 的差异？

> RoPE 位置编码 + RMSNorm + Pre-Norm + SwiGLU FFN + GQA/MQA/MLA KV 压缩 + Decoder-only + 无 bias 项 + tied embedding（部分模型）。

### Q4.2 Llama-3 70B 训了多少 token？为什么这么多？

> 15T tokens，~200 tokens/param，是 Chinchilla 最优（~20×）的 10 倍。原因是推理友好——同等部署成本下更小的模型多训点比更大的模型少训更划算。

### Q4.3 RoPE 的核心一行公式 / 直觉？

> 在 Q,K 上对每对维度做**位置相关的复数旋转**：`RoPE(q, m)[2i:2i+2] = R(m·θ_i) · q[2i:2i+2]`，使得 `<RoPE(q,m), RoPE(k,n)>` 只依赖 `m-n`，相对位置自然涌现。

### Q4.4 BBPE 处理中文为什么需要 SentencePiece 风格的 `▁`？

> BBPE 直接处理 byte 不需要 `▁`；`▁` 是 SentencePiece 的设计——把空格当 token 让"无空格"和"有空格"语言统一处理。Llama-3 用纯 BBPE 已经无 `▁`，反而对中日韩更自然。

### Q4.5 Pre-Norm 为什么训练稳定？

> 梯度从 residual 路径直通到底层，避免了 Post-LN 在深层网络上 LN 把梯度尺度压缩导致的梯度消失；代价是表达力略弱（残差直通过强），DeepNet 给残差缩放是补偿。

### Q4.6 为什么现代 LLM 普遍不加 bias？

> 经验：bias 在大模型里贡献很小，去掉省参数、省 KV cache 显存（attention bias 也省）、对量化更友好。Llama 2/3、DeepSeek 都不加。

### Q4.7 BPE 词表大小怎么选？

> 权衡：词表大 ⇒ 单 token 信息密度高、推理快，但 embedding 矩阵参数爆炸（V × d）；词表小 ⇒ 序列变长，训推变慢。Llama-3 选 128K（多语友好），GPT-4o cl100k 用 200K。
