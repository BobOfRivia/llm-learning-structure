# 7.1 线性注意力（RWKV / RetNet / Lightning / GLA）

[← 返回框架](../../README.md) · [📎 materials.md → §7.1](../../materials.md)

## 〇、为什么需要"线性"

§5、§6 的所有方法（FA、GQA、MLA、稀疏 attention）都还在 softmax-attention 框架内：
- 训练复杂度 $O(L^2)$（即使有 FA 把常数压低）
- 推理 decode 阶段每步要遍历整个 KV-cache，KV 大小 $O(L)$

线性注意力（Linear Attention）走另一条路：

> 把 softmax 拆掉，让 attention 等价为一个 **RNN 风格的累加状态**。
> 训练时仍可 parallel（partial sum trick），推理时是 **$O(1)$ 状态 + $O(L)$ 总时间**。

```
softmax attention:    Q · softmax(K^T) · V       —— L 长，state 随 L 增长
linear attention:     Q · (K^T · V)              —— state 大小固定 = d × d
                          ↑ 关联律重排
```

---

## 一、数学起点：去掉 softmax

标准 attention：
$$O_i = \sum_j \frac{\exp(Q_i^\top K_j)}{\sum_{j'} \exp(Q_i^\top K_{j'})} V_j$$

把 $\exp$ 换成一个**核函数** $\phi(\cdot)$（如 ELU+1、ReLU、cos/sin、identity）：
$$O_i = \frac{\sum_j \phi(Q_i)^\top \phi(K_j) V_j}{\sum_j \phi(Q_i)^\top \phi(K_j)}$$

由于矩阵乘法满足**结合律**：
$$O_i = \frac{\phi(Q_i)^\top \cdot \sum_j \phi(K_j) V_j^\top}{\phi(Q_i)^\top \cdot \sum_j \phi(K_j)}$$

令 $S_i = \sum_{j \le i} \phi(K_j) V_j^\top$（一个 $d \times d$ 矩阵）、$z_i = \sum_{j \le i} \phi(K_j)$（一个 $d$ 维向量）：

$$O_i = \frac{\phi(Q_i)^\top S_i}{\phi(Q_i)^\top z_i}$$

→ $S_i$ 和 $z_i$ 都可以**增量更新**（RNN 风格），不必保留所有 K, V。

```
recurrent 形式（decode 时）：
  S_t = S_{t-1} + φ(K_t) V_t^T     # d×d 矩阵
  z_t = z_{t-1} + φ(K_t)           # d 维
  O_t = φ(Q_t)^T S_t / φ(Q_t)^T z_t
```

→ **state = 固定 d²，与序列长度无关**。1M context 推理 KV 占用与 1k 一样。

---

## 二、训练时怎么 parallel

只看 recurrent 形式像 RNN，慢。线性 attention 的关键是**训练时可并行**：

### 2.1 Chunked / Parallel Form

把序列切成 chunk（如 chunk size = 64）：
- **chunk 内**：用 attention 风格的 matmul（短，可并行）
- **chunk 间**：用 recurrent 风格累加 state

```
chunk 1 → 算出 chunk 内 attention + 累出 S₁
chunk 2 → 用 S₁ 作为初始 state + 算 chunk 内 + 输出 S₂
...
```

→ 训练吞吐与标准 attention 相当（甚至更快），但**复杂度严格 $O(L)$**。

### 2.2 Lightning Attention 等工程实现

[Lightning Attention](https://arxiv.org/abs/2401.04658)（MiniMax）就是把这套并行算法写成 FA-style 的 fused kernel：
- chunk size 自动调优
- 与 BF16/FP16 数值稳定
- 现已支持 H100 + FP8

## 三、主要线性注意力变体

### 3.1 Linear Transformer（[Katharopoulos 2020](https://arxiv.org/abs/2006.16236)）

最早系统地把"去 softmax + 结合律重排"提出来的工作，用 $\phi(x) = \text{ELU}(x)+1$。
质量明显低于 softmax attention，主要价值是开了这条路。

### 3.2 Performer / FAVOR+（[Choromanski 2020](https://arxiv.org/abs/2009.14794)）

用**随机特征**逼近 softmax kernel：
$$\exp(q^\top k) \approx \mathbb{E}[\phi(q)^\top \phi(k)]$$
理论好看，实测在 NLP 上质量不如其他变体，淡出。

### 3.3 RetNet — Retentive Network（[Sun et al. 2023, MSRA](https://arxiv.org/abs/2307.08621)）

提出"**Retention**"——线性 attention + 衰减项：
$$S_t = \gamma S_{t-1} + K_t^\top V_t$$

其中 $\gamma \in (0, 1)$ 是**指数衰减系数**（不同 head 不同 $\gamma$）。
→ 类似 RNN 的 forget gate，能"忘掉"远距离信息。

三种等价形式：
- **Recurrent**：decode 时用，$O(1)$ state
- **Parallel**：训练时用，$O(L^2)$ 但常数小
- **Chunkwise**：长序列训练，分块 + state 传递

性能：在 1B-7B 规模上，质量接近标准 Transformer，推理快 3-8×。但 30B+ 规模上明显掉点。

### 3.4 RWKV — Receptance Weighted Key Value（[Peng et al. 2023+](https://arxiv.org/abs/2305.13048)）

中国社区主导的开源线性 RNN：
- 把 attention 改成 channel-wise 的"time mixing"
- 把 FFN 改成 "channel mixing"
- 公式上等价为一种带衰减的线性 attention

```
RWKV time-mixing:
  state_t = e^(-w) ⊙ state_{t-1} + e^k_t ⊙ v_t      # 类似指数移动平均
  out_t   = receptance_t ⊙ (state_t / norm_t)
```

特点：
- **纯线性**：训练、推理都 $O(L)$
- 推理 state 只有 $O(d)$（不是 $d^2$）→ 内存极省
- 已迭代到 RWKV-7（"Goose"），14B 规模能比肩 Llama-2
- 缺点：复杂 reasoning、long-context recall 不如 Transformer

### 3.5 Lightning Attention v1 / v2（[MiniMax 2024](https://arxiv.org/abs/2401.04658)）

把线性 attention 做成 FA 风格的高效 kernel：
- v1：chunk parallel + recurrent，纯线性
- v2：加上 sliding window 形成 "**Lightning Attention-2**"，本质是混合
- 部署在 **MiniMax-01**（456B 参数），1M context 实测可用

### 3.6 GLA — Gated Linear Attention（[Yang et al. 2023](https://arxiv.org/abs/2312.06635)）

给线性 attention 加上"**逐 token 的 gate**"：
$$S_t = G_t \odot S_{t-1} + K_t^\top V_t$$

其中 $G_t$ 是依赖输入的 forget gate（不是固定 $\gamma$）。
→ 类似 LSTM/GRU 的门控，给"何时忘记历史"加了 data-dependent 自由度。

→ 这是后来 **Mamba** 的核心 motivation 之一（"selective state"）。

### 3.7 DeltaNet / RWKV-7 / TTT

**DeltaNet**（[Schlag 2021](https://arxiv.org/abs/2102.11174) → [Yang 2024 Generalized DeltaNet](https://arxiv.org/abs/2406.06484)）：
- 把 state 更新写成"**Delta rule**"：$S_t = S_{t-1} + (V_t - S_{t-1} K_t) K_t^\top$
- 给 state 多了一个"擦除-写入"的能力，长程 recall 更强

**RWKV-7 / TTT (Test-Time Training)**：让 state 更新成为"小型在线训练"
- 当前研究热点：Mamba-2、Hawk、Griffin、Hyena 都在这条线上演进

## 四、关键问答

**Q1**：线性 attention 为什么"训练强、推理快"？
- 训练：chunk parallel 后训练吞吐与 softmax attention 同档
- 推理：state 大小固定 → decode 只读 $O(d^2)$ 而非 $O(Ld)$
- 在 64k+ context 上 decode 速度差距能拉到 5-10×

**Q2**：线性 attention 质量为什么差一点？
- softmax 的"指数选择"提供了一种强 sharp focus 能力（像精确检索）
- 线性 attention 把"匹配"摊平成内积，**对 long-context retrieval 弱**（"针在草堆里"等任务掉点）
- 这是当前主要 gap

**Q3**：为什么 RWKV state 是 $O(d)$ 而 RetNet 是 $O(d^2)$？
- RWKV 用 channel-wise 衰减，每个 channel 独立 → state 维度 = d
- RetNet 保留了"K^T V"外积形式 → state 是 $d \times d$
- RWKV 更省内存但表达力略弱（不能 cross-channel 路由）

**Q4**：训练时还需要 attention mask 吗？
- 因果性自动满足：recurrent state 只累加过去
- 但 chunked 形式中，chunk 内部仍需要 causal mask（chunk 内还是 attention）

**Q5**：线性 attention 是不是 RNN？
- 数学上等价于一种"具有矩阵 state 的线性 RNN"
- 但训练时是 parallel form（不像 LSTM 必须 sequential）
- 这是 2020 后的关键突破：**RNN 的 sequential bottleneck 在线性 attention 下被绕开**

**Q6**：当前工业界谁在用？
- **MiniMax-01**：Lightning Attention + softmax 混合（见 §7.3）
- **RWKV**：开源社区，14B 规模有产品落地
- **Mamba 系**：见 §7.2
- **主流大厂（OpenAI/Anthropic/Meta/Google）**：仍以 softmax + FA 为主，混合架构在试

**Q7**：线性 attention 会取代 softmax attention 吗？
- 短期不会（质量 gap 还在）
- 长期方向：**混合架构**——少量 softmax 层 + 大量线性层（见 §7.3）
- 这是当前共识："要 retrieval 用 softmax，要长 context throughput 用线性"

## 五、与其他方法对比

| 方法 | state 大小 | 训练复杂度 | decode 复杂度 | 质量 vs softmax |
|------|-----------|-----------|--------------|----------------|
| Softmax (MHA) | $O(Ld)$ | $O(L^2 d)$ | $O(Ld)$/step | baseline |
| GQA | $O(Ld/g)$ | $O(L^2 d)$ | $O(Ld/g)$ | ≈ |
| MLA | $O(L d_c)$ | $O(L^2 d)$ | $O(L d_c)$ | ≈/↑ |
| Sliding window (Mistral) | $O(wd)$ | $O(Lwd)$ | $O(wd)$ | ↓ slight |
| NSA / MoBA | $O(L d)$ | $O(L \cdot k \cdot B d)$ | $O(k B d)$ | ≈ |
| **Linear attention (RetNet)** | $O(d^2)$ | $O(Ld^2)$ | $O(d^2)$/step | ↓ slight |
| **RWKV** | $O(d)$ | $O(Ld)$ | $O(d)$/step | ↓ moderate |
| **Mamba (§7.2)** | $O(d \cdot n)$ | $O(Ldn)$ | $O(dn)$/step | ↓ slight |
