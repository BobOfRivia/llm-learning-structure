# 2.5 残差结构与梯度流

[← 返回框架](../../README.md) · [📎 materials.md → §2.5](../../materials.md)

## 一、残差连接（Residual Connection）

每个 sublayer 的输出：
$$x_{l+1} = x_l + F(x_l)$$

其中 $F$ 是 attention 或 FFN。这条 `+x` 的恒等捷径是 Transformer 能堆深的根本原因。

**起源**：ResNet (He et al. 2015)，原本是为视觉网络解决"训得越深错越大"的退化问题。

---

## 二、为什么残差能让网络变深

### 2.1 梯度的角度

反向传播时：
$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_{l+1}} \cdot \left(I + \frac{\partial F}{\partial x_l}\right)$$

- 没有残差：$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_{l+1}} \cdot \frac{\partial F}{\partial x_l}$，多层连乘容易消失/爆炸
- 有残差：$I + \frac{\partial F}{\partial x_l}$ 中**恒等项保证下界**，梯度可以"绕过"$F$ 传到底层
- 这是**梯度高速公路**的几何意义

### 2.2 函数的角度

残差让每个 sublayer 学的是**增量** $F(x) = $ 输出 − 输入，而非全量映射。
- 增量学习更容易（初始化时 $F \to 0$ 也不会破坏前向）
- 各层是"迭代精炼"而非"重新计算"

### 2.3 残差路径与表示空间

Anthropic 的 [transformer-circuits](https://transformer-circuits.pub/2021/framework/index.html) 提出**residual stream** 视角：
- 残差通路是一个"共享读写总线"
- 每个 sublayer 从 stream 读 → 处理 → 写回 stream
- token embedding 和 LM head 直接连到 stream 两端
- 这种视角解释了为什么"早层学语法、深层学语义"

## 三、Pre-Norm vs Post-Norm 下的梯度

### 3.1 Post-Norm

$$x_{l+1} = \text{Norm}(x_l + F(x_l))$$

- 残差**被 Norm 二次缩放**
- 梯度逐层乘以 Norm 的 Jacobian
- 深层网络梯度衰减 / 爆炸（需 warmup）

### 3.2 Pre-Norm

$$x_{l+1} = x_l + F(\text{Norm}(x_l))$$

- 残差是**纯恒等**（$+x_l$ 不经过任何变换）
- 梯度可以直接从最深层一路传到 embedding
- 训练稳定，但"有效深度"被稀释（深层的 F 容易被加和淹没）

```
Post-Norm:
    ┌──────────────┐
    │ x → F → +x → Norm → next
    │                            
    └──→ 梯度被每层 Norm 衰减
                  
Pre-Norm:
    ┌──────────────────┐
    │ x → Norm → F → +x → next
    │ │
    │ └→ 残差通路恒等无损
    └────────────────→ 梯度高速公路
```

## 四、初始化与残差

为了让训练初期 $F \approx 0$、$x_{l+1} \approx x_l$：

- **小初始化**（如 $\sigma = 0.02$）+ Norm → 初始 $F$ 输出量级 $\ll x$
- **Fixup / SkipInit**（学术）：手工设计参数让 $F$ 初始为 0
- **DeepNorm**：缩放残差路径 $\alpha \cdot x + F$，$\alpha = (2N)^{1/4}$
- **Llama 系**：每个 sublayer 输出权重按 $\frac{1}{\sqrt{2N}}$ 缩放，使方差稳定

---

## 五、残差流的"读写"模式

| Sublayer | 读 | 写 |
|----------|-----|-----|
| Attention | Q/K/V 从 stream 投影 | O 投影写回 stream |
| FFN | W_up / W_gate 读 | W_down 写回 |
| LayerNorm | 读 + 归一化 | 不写残差，只过 sublayer |

> 关键结论：**stream 维度 = $d_{model}$**，每层 sublayer 都在这个共享空间内做加法编辑。
> 这也解释了为什么 attention 的 Q/K/V/O 投影 + FFN 升降维需要回到 $d_{model}$。

---

## 六、梯度流的实证现象

- **early layers vanishing**：Post-Norm 深层模型最底层梯度极小（GPT-1 之后弃用）
- **gradient norm 监控**：训练大模型时通常监控每层的梯度范数曲线
- **loss spike**：训练中常见的 loss 突然爆炸 → 多与残差路径 / norm 数值不稳定有关
- 工业实践：
  - 配合 gradient clipping（常见阈值 1.0）
  - learning rate warmup（线性升到峰值后 cosine）
  - 训练中重启已成共识（DeepSeek-V3 实际有多次 rollback）

---

## 七、激活值的"residual norm explosion"

随着层数加深，残差累积 → $\|x_l\|$ 单调增大：
- 实测 Llama-2 70B 第 80 层 $\|x\|$ 比第 1 层大 100×
- 这会让**最后几层 Norm 的输出值范围扩大** → 量化困难
- **outlier features** 现象：少数维度方差极大（[Dettmers et al. 2022 LLM.int8](https://arxiv.org/abs/2208.07339)）
- 推动了 SmoothQuant、AWQ 等量化方法的发展

## 关键问答

**Q1**：没有残差，Transformer 能训几层？
- ResNet 之前的 plain net 最多 20-30 层
- Transformer 没残差实测 6-12 层就训不动
- 残差 + Pre-Norm 让 100+ 层成为可能（DeepNet 可训 1000 层）

**Q2**：残差为什么必须是恒等连接？
- 数学上：$I + \partial F$ 的 $I$ 是梯度下界保证
- 工程上：投影残差（$Wx + F$）会丢失 stream 信息
- 例外：维度变化时需要 $1 \times 1$ 卷积或线性投影（ResNet 中的 downsample）

**Q3**：Pre-Norm 让模型"等效变浅"是什么意思？
- $x_l = x_0 + \sum_{i<l} F_i(\text{Norm}(x_i))$
- 当 $L$ 大时，许多 $F_i$ 输出量级远小于 $x_0$ → 被加和淹没
- 网络的"有效深度"小于 $L$（Veit et al. 2016 "unraveled view"）

**Q4**：DeepNorm 的 $\alpha = (2N)^{1/4}$ 怎么来的？
- 通过约束输出方差稳定推导，目标是让训练时每层 update 量级与层数无关
- 让 Post-Norm 在 1000 层也能稳定训
- 但现代 SOTA 仍偏好 Pre-Norm + 小初始化

**Q5**：残差和量化的关系？
- 残差累积导致激活 outlier，是量化困难的根因
- AWQ、SmoothQuant、LLM.int8 都在处理这个
- DeepSeek 团队的 FP8 训练用了"per-tile scaling" 等技巧

**Q6**：能不能只在部分层加残差？
- 学术上有探索（如 Gated Residual）
- 工业模型几乎都是"每个 sublayer 都有残差"
- 例外：encoder-decoder 的 cross-attention 也有残差，结构对称
